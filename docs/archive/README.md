# Documentation Archive

Files in this directory are retained for design history, decision provenance, and old implementation context. They are not current operating instructions or architecture authority.

Use current documents from [`../README.md`](../README.md) before reading anything here.

## Archive Map

| Directory | Content |
|---|---|
| `specifications/` | Superseded Mission Control and Project requirements |
| `completion-notes/` | Historical phase delivery notes |
| `legacy-hermes/` | Old Hermes/VPS setup, cost, troubleshooting, and spike material |
| `roadmaps/` | Superseded MMO-oriented schedules |

Archived documents are intentionally kept close to their original content. Their status claims, links, model names, prices, paths, commands, security assumptions, and implementation descriptions may be wrong today.

Do not update an archived file to describe the current system. Update the active docs and, when needed, add a note to [`../DOCUMENTATION_AUDIT.md`](../DOCUMENTATION_AUDIT.md).
